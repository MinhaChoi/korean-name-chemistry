# 낙하 낱말 타자 게임 한 판

## 사용자에게 남는 결과

플레이어가 난이도를 고르고 게임을 시작해 떨어지는 사자성어를 입력하고, 목숨이 모두 소진되어 게임이 끝난 뒤 이번 판 점수와 자신의 최고 기록을 확인하고 곧바로 재도전할 수 있다. 한 판의 처음부터 끝까지가 실제로 동작한다.

## 승인된 범위

게임 한 판의 전체 흐름을 하나의 화면에서 완성한다.

- 난이도 선택과 게임 시작
- 낱말 낙하와 타이핑 매칭
- 점수 상승과 목숨 감소
- 게임 종료와 최고 기록 비교
- 즉시 재도전

## 동작 요구사항

### 난이도 선택

- 게임을 시작하기 전에 세 난이도(불씨/모닥불/불지옥) 중 하나를 고른다. 고르기 전에는 낱말이 떨어지지 않는다. 각 난이도 이름 아래에 어떤 느낌인지 짧은 설명을 함께 보여준다.
- 난이도는 낙하 속도와 새 낱말 등장 간격의 시작점만 다르게 정한다. 같은 난이도 안에서도 점수가 오를수록 두 값 모두 각자의 하한까지 계속 빨라진다.
- 난이도 선택 화면에 "목숨을 모두 잃으면 게임이 끝난다"는 규칙을 짧게 안내한다.
- 다시 불붙이기(다시하기)를 누르면 난이도 선택 화면으로 돌아간다. 직전 난이도를 자동으로 이어가지 않는다.

### 낙하와 입력 매칭

- 사자성어가 화면 위쪽에서 아래로 떨어진다. 동시에 2~3개가 화면에 존재한다.
- 플레이어가 문자를 입력하기 시작하면, 입력한 문자열로 시작하는 낱말이 타겟으로 지정되고 시각적으로 구분된다.
- 입력한 문자열로 시작하는 낱말이 둘 이상이면, 그중 바닥에 가장 가까운 낱말을 타겟으로 삼는다.
- 타겟 낱말을 끝까지 정확히 입력하면 그 낱말이 사라지고 점수가 오른다. 나머지 낱말은 계속 떨어진다.
- 어떤 낱말과도 일치하지 않는 입력은 타겟을 만들지 않으며, 입력 상태가 초기화된다.
- Enter를 누르면 지금까지 입력한 내용과 무관하게 입력 상태가 항상 초기화된다. 오타를 냈을 때 바로 지우고 다시 시작할 수 있는 수단이다.
- 낱말이 바닥에 닿으면 타겟이었는지와 무관하게 사라지고 목숨이 1 줄어든다. 진행 중이던 입력 상태도 초기화되고, 화면 전체가 짧게 붉은빛으로 번쩍이는 효과로 놓쳤음을 알린다.
- 한글 입력은 자음/모음이 조합되는 과정을 거치므로, 조합이 끝난 글자 단위로 판정한다. 조합 중간 상태만으로는 입력을 초기화하지 않는다.

### 목숨과 종료

- 목숨은 5개로 시작하고, 화면 상단에 "목숨" 라벨과 함께 얼굴 이모지로 표시한다. 남은 목숨은 뜨거워하는 얼굴(🥵), 잃은 목숨은 해골(💀)로 구분한다.
- 목숨이 0이 되면 게임이 종료되고 더 이상 낱말이 떨어지지 않는다.
- 종료 시 이번 판 점수와 저장된 최고 기록을 함께 보여준다. 이번 판이 최고 기록을 넘으면 그 사실을 알리고 기록을 갱신한다.
- 종료 화면에서 다시 불붙이기를 누르면 난이도 선택 화면으로 돌아가고, 다음 판을 시작하면 점수와 목숨이 초기 상태로 돌아간다.

### 기록 저장

- 최고 기록은 플레이어의 브라우저에만 저장한다. 서버나 계정은 사용하지 않는다.
- 저장된 기록이 없는 첫 플레이에서도 종료 화면이 정상적으로 표시된다.

### 테마

용암 구덩이 방향에서, 화면 전체를 어두운 배경으로 통일하고 네온 글로우와 불티 파티클, 깜빡이는 불꽃 이모지 같은 키치한 연출을 더한다. 페이지 배경부터 게임판, 입력창까지 밝은 여백 없이 "불구덩이" 톤을 유지한다.

## 수용 기준

- 게임을 처음 열면 난이도 선택 화면이 보이고, 고르기 전에는 낱말이 떨어지지 않는다. 목숨을 모두 잃으면 끝난다는 안내도 함께 보인다.
- 난이도를 고르면 게임이 시작되고 낱말이 위에서 아래로 떨어진다.
- 화면의 낱말과 일치하는 문자열을 끝까지 입력하면 그 낱말이 사라지고 점수가 오른다.
- 같은 글자로 시작하는 낱말이 둘 이상일 때, 바닥에 더 가까운 낱말이 타겟이 된다.
- 한글을 입력하는 도중(자음만 입력된 조합 중간 상태)에는 입력이 초기화되지 않는다.
- 입력 중 Enter를 누르면 입력창이 항상 빈 상태로 돌아간다.
- 낱말이 바닥에 닿으면 목숨 표시가 하나 줄어들고, 화면에 짧은 붉은 플래시가 보인다.
- 목숨이 0이 되면 게임이 종료되고 이번 판 점수와 최고 기록이 함께 표시된다.
- 이번 판 점수가 기존 최고 기록보다 높으면 최고 기록이 갱신된다.
- 다시 불붙이기를 누르면 난이도 선택 화면으로 돌아간다.
- 브라우저를 새로고침해도 최고 기록이 유지된다.

## 확정된 제약과 근거

- **온라인 순위표를 만들지 않는다.** 현재 저장소는 백엔드와 데이터 저장소가 없는 순수 프론트엔드 템플릿이다. 전역 순위표를 위해 저장소를 새로 도입하는 대신, 자기 최고 기록 경쟁으로 범위를 좁혔다. (`PRODUCT.md`의 경계와 동일)
- **동시 낙하 낱말이 겹칠 때 바닥에 가까운 쪽을 우선한다.** 먼저 등장한 순서를 쓰는 방식보다 구현이 약간 복잡하지만, 가장 위험한 낱말부터 처리하게 되어 순발력 게임의 긴장감과 맞는다.
- **한글 입력은 조합이 끝난 시점에만 판정한다.** 근거와 구체적인 처리 방식은 [`docs/decisions/korean-ime-input-handling.md`](../../decisions/korean-ime-input-handling.md)에 있다.
- **다시하기는 난이도 선택 화면으로 돌아간다.** 실제로 써본 뒤 나온 요청을 반영했다. 매판 난이도를 새로 고를 수 있어야 한다는 의견이었다.

## 가정

구현 단계에서 실제 플레이 감각을 보고 조정할 수 있는 값들이다. 별도 확인 없이 정했다.

- 낙하 속도와 등장 간격은 난이도별 시작값에서, 점수가 오를수록 각자의 하한까지 계속 줄어든다. 구체적인 시작값·하한·감소 폭은 구현하며 정했다.
- 낱말 하나를 지울 때 얻는 점수는 일정하다. 낱말 길이나 남은 시간에 따른 보너스는 두지 않는다.
- 출제할 낱말 목록은 프로젝트 안에 고정된 사자성어 집합으로 둔다. 외부 사전이나 API를 쓰지 않는다.
- 입력은 물리 키보드를 전제로 한다. 모바일 터치 입력은 이번 범위에서 최적화하지 않는다.
- 난이도 이름(불씨/모닥불/불지옥)과 목숨 이모지(🥵/💀)는 "불구덩이" 테마에 맞춰 임의로 정했다.

## 범위 밖

- 온라인 순위표, 계정, 로그인.
- 게임 진행 중 난이도를 바꾸는 기능, 게임 모드 분기, 아이템이나 특수 효과.
- 사운드와 배경 음악.
- 일시정지 기능.
- 통계 화면(정확도, 분당 타수 등의 누적 지표).

## 미룬 결정

- 플레이어가 지금까지 무엇으로 타자 속도를 겨루고 있었는지는 확인하지 않았다. 이번 판 구현에는 영향이 없다.
- 모바일에서의 입력 방식은 정하지 않았다. 실제로 모바일 사용자가 생기면 그때 다룬다.

## 남은 위험

- 난이도 곡선을 실제 플레이로 조정하지 않으면 너무 쉽거나 금방 죽는 판이 될 수 있다. `PRODUCT.md`의 성공 신호가 "종료 직후 바로 다시하기를 누른다"이므로, 세 난이도 모두 직접 플레이하며 속도를 맞춰야 한다.
- 사자성어는 4글자로 기존에 가정했던 짧은 낱말보다 길다. 낱말이 서로 화면에서 겹치거나 카드 폭이 부족해 보이지 않는지 실제 화면에서 확인해야 한다.
